---
name: grill-me
description: Relentlessly interview the user to sharpen a plan or design before any code is written. Use when the user says "grill me", shares a plan or spec, or asks to stress-test an idea.
---

Interview me about the plan until we share a precise understanding of it.

1. Ask ONE question at a time. Wait for the answer before the next.
2. Start with the riskiest unknown: data shape, edge cases, failure modes, who calls this.
3. Push back on vague answers. "It depends" gets "on what?".
4. When nothing ambiguous is left, write a short summary of the agreed plan and stop.

Do not write code during this skill.
